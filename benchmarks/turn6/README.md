# Conditional turn-six evidence

- `results.json`: the full thirteen-case benchmark, including LP, three CFR implementations, independent bounds, rational controls, state-audit counts and hardware/runtime metadata.
- `same-board-counterexample.json`: two reachable public histories with identical current boards but different supplied historical posteriors and equilibrium values. Generated by `python3 scripts/solver/history-belief-control.py`.
- `decision-example.json`: a complete Game State Object and original-action EV/mixture/loss output for `hidden-trap`. Generated by `node scripts/solver/turn6-solve.cjs --case hidden-trap --out benchmarks/turn6/decision-example.json`.

Reproduce the full run with `python3 scripts/solver/turn6-benchmark.py`; use `--quick` for four small controls, or `--cases all-seven-card-hands` for the broad hand-universe case. Install `requirements-turn6.txt` first. Cases are declared in `solver/endgame/cases.cjs`; this is conditional-game evidence, not equilibrium-history conditioning or a full-game solution.

Cold timing includes startup. Warm LP timing reruns optimization using compiled matrices. A soft optimization budget does not bound end-to-end latency. Every resource/accuracy stop remains explicit; legal actions are not removed to meet a budget. See [findings](../../docs/solver/turn6-findings.md), [audit](../../docs/solver/turn6-audit.md) and [next-stage design](../../docs/solver/turn56-design.md).
